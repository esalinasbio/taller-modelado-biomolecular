# Datos

| Archivo | Descripción | Tamaño |
|---|---|---|
| `1aud_100ns_noWAT.xtc` | Trayectoria de 100 ns sin disolvente, autoimaged y alineada | ~96 MB |
| `1aud_topologia_noWAT.pdb` | Topología correspondiente | |

La trayectoria **con** disolvente no se versiona (varios GB). Se regenera con
`scripts/preparar_datos_taller.py`.

Los cuadernos apuntan a estos archivos por URL cruda de GitHub; el campo `URL_DATOS`
de cada cuaderno es editable.
