# Taller de Modelado Biomolecular Computacional

Materiales de un taller práctico de cinco sesiones sobre modelado computacional de
proteínas y ácidos nucleicos.

Los cuadernos corren en **Google Colab**, sin instalación local.

## Contenido

| Parte | Tema | Notebook |
|---|---|---|
| 1 | Dinámica molecular | |
| 2 | Acoplamiento molecular (*docking*) | |
| 3 | Predicción de estructura y co-plegamiento | |
| 4 | Diseño de proteínas | |
| 5 | Ensambles conformacionales | |


## Estructura

```
notebooks/     cuadernos de Colab (.ipynb)
data/          trayectorias y estructuras de entrada
scripts/       preparación previa (instructor, requiere GPU local)
slides/        presentaciones
resources/     bibliografía y notas
```
